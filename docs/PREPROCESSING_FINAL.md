# NA12878 WGS Training Data — Preprocessing Results

**Project status:** Raw-read QC, adapter review, Trimmomatic preprocessing and post-trimming FastQC comparison complete. Reference validation and alignment remain pending.

## Data and methods

Public Broad Institute GATK test-data subset `s3://gatk-test-data/wgs_fastq/NA12878_20k/`; three paired-end sequencing groups, each with 10,000 read pairs, totaling 60,000 reads of 250 bp before preprocessing. Six FASTQ files were validated for pairing. FastQC and MultiQC were applied before and after trimming. The processing commands used Trimmomatic paired-end mode with `ILLUMINACLIP:<adapter FASTA>:2:30:10`, `LEADING:3`, `TRAILING:3`, `SLIDINGWINDOW:4:20` and `MINLEN:50`. The exact adapter-FASTA path/hash and command provenance should be retained from the local run records.

All six original files were 250 bp long. Post-trimming paired reads varied from 50 to 250 bp (with smaller maximum read lengths in some R2 files). GC percentages in the summary shifted from 41–42% before trimming to about 39% afterward.

## Interpretation and limitations

Trimming improved FastQC screening status across several modules and retained 79.49% of the input pairs. One trimmed file still has a per-base-quality warning. FastQC statuses alone cannot establish mapping accuracy, absence of artifacts, or reliable variant calling. This is a very sparse whole-genome *test* dataset and is not powered for robust genome-wide variant detection or benchmarking. Numerical metrics derive from the user's terminal screenshots and pre/post FastQC comparison; the original logs and ZIP reports remain the primary evidence.
